# Project Overview

Assessment V3 is an independent product built on the Growth OS framework.

It is the first product in the Growth OS ecosystem.

This project is NOT the official website.

This project is NOT the AI learning platform.

Its only responsibility is to help users complete the Self-directed Learning Assessment and receive their Growth Report.

# Product Mission

Help children understand themselves more clearly.

Help parents understand their children more objectively.

Help every family discover the next growth direction.

The product does NOT evaluate children.

The product helps children continue growing.

---

# Core Value

Users do not come here to get a score.

Users come here to answer one question:

"What is my most worthwhile direction for growth right now?"

Everything in this product should serve this purpose.

---

# Core Experience

Every completed assessment should provide users with:

• Growth Profile

• Growth Insight Report

• Growth Navigation Handbook

• Next Growth Focus

• Actionable Growth Suggestions

The report is not the product.

# Project Principles

1. Documentation First

Every feature must be implemented according to PRD.md.

Never invent product logic.

---

2. Product First

Never change business logic without documentation updates.

Documentation is the single source of truth.

---

3. Brand Consistency

Never modify brand positioning.

Never replace official copywriting.

Never rename business concepts.

---

4. Simplicity

Every page should communicate one core idea.

Every page should have one primary CTA.

Avoid unnecessary complexity.

---

5. Scalability

All business logic should be configurable.

Do not hardcode product rules.

Prepare for future integration with Learning Planet and the Official Website.
